# Contributing

Keep changes focused and use an English pull request. Check the site locally with the commands in the README and inspect desktop/mobile layouts in light and dark themes before changing presentation.

Use a GitHub noreply commit address. Run `pwsh -File scripts/check-privacy.ps1 -Staged` before committing. Commit only intentional source and public assets; local previews, build output, credentials and personal information do not belong in this repository.

Public links and statements about projects must remain accurate. Do not add trackers, external fonts, testimonials, counters or new dependencies without a clear reason. Preserve keyboard access, system theme support and reduced-motion behavior.
